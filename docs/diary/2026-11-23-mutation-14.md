### What I did

- The scripts are in `/Volumes/990/s4ql/worktree-agent-aa464ec2f3c64d4c6/scripts/`: `funcs/main.go` (built as `funcs.bin`) prints the line range of every declaration of a file under the name that the tool's keys use (`Type.Method`, or the function or the first name of a value spec); `pick.py` reads `git diff -U0 9238075..HEAD` of each file, marks every declaration that holds an added or changed line or the place of a removal, and keeps every mutant of the tool's `-list` whose key names a marked declaration of its file, as one `-run` expression of exact keys per package; `run.sh` runs the tool on a copy of the tree with `TMPDIR` on that disk and the default Go cache, which is on that disk already. `emit/` is a copy of the tool's `generate.go` with a `main` of its own that writes the file of one mutant by its key and an overlay, and `mut.sh` runs `go test -overlay` of the worktree against it, so a new test is checked against its mutant in seconds.
- The files of the selection: `internal/sql/stmt/recognize.go` and `stmt.go`; `internal/engine/engine.go`, `operator.go`, `plan.go`, `returning.go`, `telemetry.go`, and `tx.go` (`bugs.go` changed only the fields of the struct `bugs`, which have no mutants; the hooks of the planted bugs are in the functions above); and `conn.go` and `rows.go` of the root (`rows.go` changed only a comment outside any function, and `s4ql.go` only the package doc). The marked declarations:
  - `stmt`: `recognizer.insert`, `recognizer.update`, `recognizer.delete`, `recognizer.returning`, `Returning.Present`: 204 mutants.
  - the engine: `Conn.exec`, `Conn.queryText`, `Conn.write`, `Engine.order`, `Rows.Close`, `Rows.Holds`, `returnedOf`, `build.change`, `buildSink`, `insert.run`, `update.run`, `remove.run`, `Format`, `NewPlan`, `formatReturning`, `returningOf`, all of `returning.go`, `report.end`, and `Conn.writeIn`: 1,510 mutants, 349 of them in `buildSink` and 147 in `report.end`, which the slice changed in a few lines and which are mutated whole.
  - the root: `conn.QueryContext`: 45 mutants. Its `check`, which #129 changed and #130 put back, has no net change.
- The tool can mutate the root package already (`-pkgs .`, and `.` is in `listedPkgs`), so it needed no change.
