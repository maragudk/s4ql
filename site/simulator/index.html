The storage code, under faults

The storage code of s4ql runs in this page: the Go code itself, unchanged, compiled to WebAssembly, with its cache on the official SQLite WebAssembly build. S3 and time are simulated.

s4ql is built for one long-running instance per database, an app with s4ql embedded. Here requests to the app, each one SQL statement, go to one instance, and a second stands by to take over. Send one of your own.

Built from an unknown commit of internal/core and internal/engine, run by internal/simulator.
