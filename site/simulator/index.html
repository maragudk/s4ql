The storage code, under faults

The storage code of s4ql runs in this page: the Go code itself, unchanged, compiled to WebAssembly, with its cache on the official SQLite WebAssembly build. S3 and time are simulated.

s4ql is built for one long-running instance per database. Here one instance serves the reads and writes of a client, and a second stands by to take over.
